# Edo Gai's Personal Website

A three-page personal website about my studies and programming experience, built with HTML and one shared CSS stylesheet.

- `index.html`: Introduction, profile photo, course timetable, and contact form.
- `about.html`: My studies at Ruppin Academic Center and programming experience.
- `notes.html`: Weekly HTML and CSS learning notes and a lecturer's quote.

To run: Open this folder in VS Code with the Live Server extension installed. Right-click `index.html` and select **Open with Live Server**. Use the navigation links to visit the other pages.
