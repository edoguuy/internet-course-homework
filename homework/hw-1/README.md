# Edo Gai's Personal Website

A three-page personal website about me — my studies, military service, and experience in the ski industry — built with HTML and one shared CSS stylesheet.

- `index.html`: Introduction, profile photo, My journey so far, and contact form.
- `about.html`: About me — my studies, military service, work in the ski industry, interest in technology, and volunteering in Nepal.
- `notes.html`: My ski journey — from skiing as a hobby to working as an Operations Manager at Pingwin Ski in France, and how my military leadership experience helped.

To run: Open this folder in VS Code with the Live Server extension installed. Right-click `index.html` and select **Open with Live Server**. Use the navigation links to visit the other pages.
